THIS COMPUTER

Local setup

Your documents are processed here.
No cloud model or online OCR is used.

What stays local

Documents, extracted text, page previews, confirmed fields, contract history and outputs are stored in this app’s data folder. The application refuses external network requests. The AI engine uses a dedicated local address and has cloud features disabled.

Model downloads are a separate one-time setup step. Keep the app’s data folder outside iCloud, OneDrive, Dropbox and other synced folders. Local storage is protected by your computer account; the database is not independently encrypted.
